# Сайт OMG. Studio

Одностраничный сайт фотостудии «OMG. Studio, Store & School» с онлайн-записью.

## Для владельца студии

**Как устроено.** Занятость хранится в Google Таблице, на листе «Записи». Сайт читает таблицу сам. Код трогать не нужно.

**Закрыть время.** Добавьте строку:

| Дата | Время | Услуга | Статус |
|---|---|---|---|
| 2026-10-25 | 14:00 | | занято |

Дату пишите в формате год-месяц-день, время — часы:минуты (например, 09:00 или 14:00).

**Закрыть весь день.** Добавьте строку с датой и статусом «занято», а время оставьте пустым.

**Открыть время.** Удалите строку.

**Заявки с сайта** появляются в таблице сами, со статусом «записан»: услуга, имя, телефон, комментарий. Чтобы отменить запись и освободить время, удалите строку.

Сайт обновляет время раз в 3 минуты и когда посетитель возвращается на вкладку.

## Для разработчика

### Таблица и скрипт

1. Создать Google Таблицу → Расширения → Apps Script → вставить содержимое `apps-script/Code.gs`.
2. Выбрать функцию `setupSheet` и выполнить один раз (разрешить доступ). Появится лист «Записи» с заголовками и текстовым форматом колонок.
3. Развернуть → Новое развёртывание → Тип «Веб-приложение» → Запуск от имени «Я» → Доступ «Все» → скопировать адрес, который заканчивается на `/exec`.
4. Создать файл `.env` рядом с `package.json` (образец в `.env.example`):
   ```
   VITE_BOOKING_URL=https://script.google.com/macros/s/.../exec
   ```
   Без него сайт работает в демо-режиме: тестовые занятые слоты, заявки никуда не пишутся, на форме плашка «Демо-режим».
5. Адрес вшивается в сайт при сборке: после изменения `.env` заново выполнить `npm run build`.
6. При правке скрипта: Развернуть → Управление развёртываниями → Изменить → Новая версия. Тогда адрес не меняется.

Часы записи заданы в двух местах и должны совпадать: `WORK_START` / `WORK_END` в `src/data/site.ts` и в начале `apps-script/Code.gs`.

### Запуск и сборка

```
npm install
npm run dev     # локальная проверка
npm run build   # сборка в папку dist
```

Содержимое папки `dist` загрузить на любой статический хостинг. Пути в сборке относительные, поэтому сайт работает и из подпапки.

### GitHub Pages

Сайт публикуется сам при каждом push в ветку `main` (`.github/workflows/deploy.yml`). Ход сборки виден во вкладке Actions репозитория.

Чтобы включить настоящую запись, добавьте адрес скрипта в репозиторий: Settings → Secrets and variables → Actions → вкладка Variables → New repository variable, имя `VITE_BOOKING_URL`, значение — адрес `/exec`. Затем Actions → Deploy to GitHub Pages → Run workflow.

### Где что менять

- Контакты, адрес, метро, режим работы, часы записи, ссылка на политику конфиденциальности: `src/data/site.ts`
- Услуги: `src/data/services.ts`
- Отзывы: `src/data/reviews.ts` (публикуются с согласия студии)
- Цвета и шрифты: `src/index.css`
- Фото: заменить `<PhotoPlaceholder … />` в `src/components/sections/Hero.tsx` и `About.tsx` на `<img src="./photo.jpg" alt="…" />`, файлы положить в `public/`
- Карта: iframe из карточки Яндекс Карт (Поделиться → Встроить карту) вставить в `src/components/sections/Contacts.tsx` вместо блока «Здесь будет карта»

### Что ещё получить от студии

Цены, адрес и метро, режим работы и часы записи, фото, iframe карты, ссылку на политику конфиденциальности, согласие на публикацию отзывов.
